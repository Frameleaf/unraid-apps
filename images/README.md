# Frameleaf listing screenshots

## Frameleaf

The `frameleaf-*.jpg` screenshots are the product images published on
[frameleaf.app](https://frameleaf.app) and in the Frameleaf/frameleaf-app README,
converted to JPEG on 2026-11-03 because Community Apps only proxies GitHub-hosted
images. They show demonstration data.

- `frameleaf-library.jpg`: library in the web app.
- `frameleaf-search.jpg`: search in plain words.
- `frameleaf-people.jpg`: people and pets.
- `frameleaf-memories.jpg`: the memory player.
- `frameleaf-editor.jpg`: the photo editor with masks.
- `frameleaf-studio.jpg`: Studio timeline editing.
- `frameleaf-boards.jpg`: Boards filtered by colour.
- `frameleaf-apple-tv.jpg`: Frameleaf Home on Apple TV.

## Frameleaf Manager

These screenshots show the Manager 1.2.3 interface, built from
Frameleaf/frameleaf-app commit `ea95579f96aff8c85c832c305cb4716e910b2eaf`.
They were captured in a browser on 2026-11-03 using the explicit demo data from
that commit's `manager/test/ui-browser.mjs`. No production instance, customer
media, credentials or private host configuration was used.

- `manager-overview.jpg`: library overview, metrics and managed services.
- `manager-storage.jpg`: mounted media storage and access modes.
- `manager-backups.jpg`: encrypted database recovery points and media exclusion.

Displayed counts, paths, service states and application releases are examples.
They do not establish application release availability or physical Unraid
qualification. The UI and Frameleaf brand assets retain their existing licenses;
see the root LICENSE and the source release's `manager/ui/public/assets/NOTICE.md`.
